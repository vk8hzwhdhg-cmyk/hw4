# Home page hero

| File | Committed? | What it is |
|---|---|---|
| `yale-bulldog-blue-banner.webp` | **No** (git-ignored, like the product photos) | The lifestyle banner from yalebulldogblue.com (2000×791), provided by the owner. It's shown whole at the top of the home page, with the headline below. |
